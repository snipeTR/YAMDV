# YAMDV — Commands for the top toolbar (icon list)

**Source:** UI_SPEC §B.7.2 (the right-click / ⋯ menu), the commands added in v2, and the action names in SHORTCUTS.md.
**ID column:** the command name in the program. IDs marked *(new)* do not exist as keymap actions yet; they are proposals for when the toolbar is built.
**★** = a frequently used command, suggested for the thin top bar. Not all ~85 commands fit in the bar; the rest can stay in the menu.

---

## Brief for the icon AI (give this part as is)

Design an **original** icon set for a native Windows Markdown viewer/editor called YAMDV. The icons go in a **thin top toolbar** and in menus.

**Format**
- One SVG per command, named `<id>.svg` (the IDs from the tables below).
- `viewBox="0 0 24 24"`, with 2 px padding (20 × 20 live area).
- Each icon must read clearly at **16 px** and **20 px**.

**Style**
- Line icons: stroke **1.5 px**, round caps and joins, pixel-aligned.
- Fill only for small accents.
- **One color only: `currentColor`** (no fixed colors, gradients or shadows), so the app can tint every icon for light mode, dark mode and Windows High Contrast.
- The same visual weight and corner style across the whole set; modern and calm, close to Windows 11 Fluent in spirit.
- **Do not copy** any existing icon set; every icon must be your own design, because the project is AGPL open source.

**Letters**
- Use letters only where they are the standard symbol: **B** (bold), **I** (italic), **S** (strikethrough), **H1 / H2 / H3** (headings).
- Elsewhere, use no text in the icons.

**Two-state commands** need two icons:
- `toggle_favorite_off` (outline star) and `toggle_favorite_on` (filled star);
- `theme_system`, `theme_light` and `theme_dark` for the three theme modes.

**Deliver**
- all SVGs;
- one review sheet (PNG) that shows every icon at 16, 20 and 24 px, on a white and on a dark (#1e1e1e) background, with its ID under it.
